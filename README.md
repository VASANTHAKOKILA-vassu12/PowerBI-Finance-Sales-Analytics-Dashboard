# PowerBI-Finance-Sales-Analytics-Dashboard
📊 Project Overview  This project focuses on analyzing sales, profit, units sold, and regional performance using Power BI. The dashboard provides actionable insights into product performance, country-wise sales, monthly trends, and profitability to support business decision-making.

🗂 Dataset

Source: Sample Sales / Finance dataset (Excel)

Data includes:

Sales, Profit, Quantity

Product, Segment, Region, Country, State

Order & Ship details

Data cleaning and transformation done using Power Query Editor

🛠 Tools & Skills Used

Power BI Desktop

Power Query (Data Cleaning & Transformation)

DAX Measures

Data Modeling

Data Visualization

Business Analysis

📈 Dashboard Pages & Insights
📄 Page 1 – Finance Overview

Total Sales: ₹11.87 Cr

Total Units Sold: 11.25 Lakh

Sales trend shows peak performance in October & December

Segment-wise analysis reveals Government and Small Business as top contributors

📄 Page 2 – Geography & Pricing Analysis

Country-wise sales and profit visualized using Map visuals

Sale price categories show higher profit contribution from premium pricing segments

Gauge visual used to track overall sales performance vs target

📄 Page 3 – Product Performance

Combined bar & line chart compares Sales vs Profit by Product

Paseo is the top-performing product in both sales and profit

Helps identify high-revenue but low-profit products

📄 Page 4 – Country & State Analysis

Country-wise and state-wise sales using table visuals

Conditional formatting highlights top and low-performing regions

Useful for regional business strategy

📌 Key Business Insights

Sales are seasonal, with strong Q4 performance

Few products contribute majority of revenue (Pareto principle)

Some regions show high sales but low profit, indicating pricing or cost issues

Premium-priced products generate higher profitability
